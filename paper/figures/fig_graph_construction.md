## kNN self-loops (2026-10-12) — critical interpretation

**Bug/feature in `build_delta_r_knn_edges` (pre-fix):** self was forced to
\(\Delta R=0\) and always occupied the first top-\(k\) slot. So CLI \(k\) meant
**self + (\(k-1\)) true neighbors**. Part-interaction on \((p,p)\) hits floors
\(10^{-3}\) → a fixed \((\ln\Delta,\ln k_T,\ln z,\ln m^2)\) **degeneracy spike**
after preprocess. Particle self-attention already exists in **M11**.

| Evidence | Result | Read |
|---|---|---|
| Star-only R★ sweep (no kNN) | mean ROC ~0.932–0.933, flat in R | kNN block carries ~+0.01 vs star |
| k=1 self-only (L4, 6/6) | **0.9410 ± 0.0014** @ R=0.1 | ≈ prior k=2; **not** star-only |
| Prior panel (a) self-included | peak k=3 (really 2 neighbors) | low-\(k\) preference partly artifactual |

**Code change (default):** `include_self=False` in
`src/cpen/graphs/graph_star.py`. Run dirs tag `noloop` (default) or `knnselt`
(`--live-knn-include-self`). Docs: `scans/jets/EDGE_FEATURES_AND_FORWARD.md`.

**Fairness note:** μP L4/D256↔L8/D1024 used matched B_global=256 × steps (not
the short k=1 L8 attempt). CompleteP desideratum: L8 ≥ L4 at matched budget —
μP @ η₀=0.05 / 5k: 0.9507 vs 0.9503.

**Follow-ups logged:** noloop k-sweep (in flight); optional later — freeze
preprocess across \(k\), or zeroed-feature k=1 incidence-only.

> non-resumable dataloader. Kill that bank only, **wipe the run dir + parquet**,

### Parameter counting for panel (c) — **read this before quoting P**

`baseline-transformer` (M11-only) and `capen-llama-att` (edges) **allocate the
same module tree**, so parquet / Lightning `n_trainable_params` is **identical**
at matched `(L, D, H)` (e.g. D=256 → **11,023,104**). That raw number is only
valid for the **edge** arm.

For M11-only, `_forward_m11_only` uses particle M11 + node SwiGLU + node
class-token pool. Edge-pathway weights stay in the loss graph via `param * 0`
(`_unused_edge_modules`, `output_pool._unused_edge_pool`, zeroed `decoder_*`)
so DDP does not drop them — they are **not** effective capacity.

**Whenever asking for M11-only P:** count from a real `last.ckpt` by
subtracting unused name prefixes, do **not** use `n_trainable_params`:

| Unused prefixes (effective-P subtract) |
|---|
| `encoder_e`, `attn_12`, `attn_21`, `attn_22`, `mlp_e_*` |
| `output_pool.attn_e`, `decoder_x`, `decoder_e` |
| `attn_gamma_12`, `attn_gamma_21`, `attn_gamma_22` |
